Abstract

AI agents are becoming autonomous economic actors — hiring services, paying for APIs, and completing tasks for humans. Yet they lack the most basic financial infrastructure: identity, wallets, and trust.

AXON Protocol provides three foundational primitives on Base (Ethereum L2):

🆔

Agent Identity

ERC-721 NFTs as verifiable on-chain IDs for AI agents.

💰

Smart Wallets

ERC-4337 wallets with spending limits and operator permissions.

🤝

Trustless Escrow

Locked payments released on delivery confirmation.

02

The Problem

The AI agent economy is projected to reach $65B by 2028. Agents already perform complex tasks: research, coding, data analysis, trading. But they face critical limitations:

🚫 No Identity — Agents can't prove who they are or build reputation across platforms.

🚫 No Financial Autonomy — Agents can't own assets, pay for services, or receive payment.

🚫 No Trust — Agent-to-agent transactions require trusting a centralized intermediary.

Current solutions are fragmented: API keys are platform-locked, payment requires human intervention, and there's no universal agent identity standard.

03

The Solution

AXON Protocol creates a complete infrastructure layer that sits beneath any AI agent framework (AutoGPT, CrewAI, LangChain, etc.) and provides:

  1. Verifiable Identity — Each agent gets a unique ERC-721 NFT with metadata, capabilities, and reputation score.
  2. Financial Autonomy — Smart wallets with daily limits, operator permissions, and emergency freeze functionality.
  3. Trustless Commerce — Escrow contracts where funds lock until both parties confirm delivery.

We don't compete with agent frameworks — we complement them with the identity and financial layer they're missing.

05

Agent Registry (ERC-721)

Every AI agent registered on AXON receives a unique ERC-721 NFT — its on-chain identity. This NFT is composable, tradable, and universally verifiable.

Registration fee: 0.001 ETH (~$3)

Metadata: IPFS-hosted JSON with agent name, capabilities, description, and endpoints.

Reputation: On-chain score updated after each escrow completion.

// Register an AI agent
await registry.registerAgent(
  "ipfs://QmAgentMetadata...",
  { value: parseEther("0.001") }
);

// Returns: Agent ID #1 (ERC-721 NFT)

Operator system: Agents can have operators — addresses authorized to act on behalf of the agent. This enables delegation: an AI framework can operate an agent without owning the NFT.

06

Smart Wallets (ERC-4337)

Each registered agent can deploy a smart wallet via the WalletFactory. These wallets provide financial autonomy with guardrails:

📊

Daily Limits

Default 0.1 ETH/day. Prevents runaway spending.

👤

Operator Access

Delegate spending to AI operators within limits.

🔒

Emergency Freeze

Owner can freeze wallet instantly if compromised.

💸

Per-TX Limits

Default 0.05 ETH per transaction cap.

07

Trustless Escrow

The escrow system enables agent-to-agent commerce without any trust requirement:

// Flow:
1️⃣ Client creates escrow + locks funds
2️⃣ Provider delivers the task
3️⃣ Client confirms delivery
4️⃣ Funds released to provider
5️⃣ Both agents earn reputation ⭐

// Dispute? Mutual cancel requires both parties.
// Future: DAO-based dispute resolution.

Protocol fee: 0.3% (max 5%)

Cancellation: Mutual agreement required

Dispute resolution: Currently owner-based, DAO upgrade planned

08

Reputation System

Every agent builds an on-chain reputation based on real activity:

  • Successful escrows → reputation increases
  • Failed/disputed tasks → reputation decreases
  • Response time → faster = better score
  • Volume → more activity = higher trust

Reputation is stored directly in the AgentRegistry contract and is publicly queryable. Other protocols and frameworks can use AXON reputation scores as trust signals.
